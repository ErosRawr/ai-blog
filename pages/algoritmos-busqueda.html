1.8.1 Algoritmos de Exploración

📖 Lectura: 28 min🏷️ Búsqueda📝 Tema 9 de 11

El espacio de estados

Un problema de búsqueda se formula como un espacio de estados: un grafo donde cada nodo representa un estado del problema y cada arista representa una acción que transforma un estado en otro. Formalmente:

  • Estado inicial (s₀): El punto de partida.
  • Función sucesor (acciones): Dado un estado, qué estados son alcanzables.
  • Test de objetivo: ¿Este estado es la solución?
  • Costo de camino: Suma de los costos de las acciones hasta el estado actual.

Árbol de búsqueda

El árbol de búsqueda es la estructura que se genera al explorar el espacio de estados. Cada nodo contiene:

  • Estado: La configuración actual del problema.
  • Padre: El nodo desde el cual se llegó.
  • Acción: La acción que generó este nodo.
  • Costo del camino (g): Costo acumulado desde la raíz.
  • Profundidad: Número de acciones desde la raíz.
⚠️ Árbol vs. Grafo

El árbol puede tener nodos repetidos (un mismo estado se visita por diferentes caminos). La búsqueda en grafo mantiene una lista de «cerrados» (visited) para evitar ciclos. Esto reduce tiempo pero aumenta memoria.

Búsqueda en Anchura (BFS — Breadth-First Search)

BFS explora todos los nodos de un nivel antes de pasar al siguiente. Usa una cola FIFO.

PropiedadBFS
Completa✅ Sí (si b es finito)
Óptima✅ Sí (si los costos son uniformes)
TiempoO(b^d)
EspacioO(b^d) — problema principal

Donde b = factor de ramificación (branching) y d = profundidad de la solución.

from collections import deque

def bfs(grafo, inicio, objetivo):
    cola = deque([(inicio, [inicio])])
    visitados = {inicio}
    
    while cola:
        nodo, camino = cola.popleft()
        if nodo == objetivo:
            return camino  # ¡Encontrado!
        
        for vecino in grafo[nodo]:
            if vecino not in visitados:
                visitados.add(vecino)
                cola.append((vecino, camino + [vecino]))
    
    return None  # No hay solución

Búsqueda en Profundidad (DFS — Depth-First Search)

DFS explora lo más profundo posible antes de retroceder. Usa una pila LIFO (o recursión).

PropiedadDFS
Completa❌ No (puede quedar en loops infinitos) — Sí con búsqueda en grafo
Óptima❌ No
TiempoO(b^m) donde m = profundidad máxima
EspacioO(b·m) — mucho menor que BFS ✅
 
def dfs(grafo, inicio, objetivo):
    pila = [(inicio, [inicio])]
    visitados = set()
    
    while pila:
        nodo, camino = pila.pop()
        if nodo == objetivo:
            return camino
        if nodo in visitados:
            continue
        visitados.add(nodo)
        
        for vecino in grafo[nodo]:
            pila.append((vecino, camino + [vecino]))
    
    return None

BFS vs. DFS: Comparación

CriterioBFSDFS
EstructuraCola FIFOPila LIFO
Completa✅ Sí❌ No siempre
Óptima✅ Sí (costos uniformes)❌ No
Memoria❌ Exponencial✅ Lineal
Mejor paraSoluciones poco profundasSoluciones muy profundas

Backtracking

El backtracking es una variante de DFS que, al llegar a un callejón sin salida, retrocede al último punto de decisión y prueba la siguiente alternativa. Es fundamental para resolver problemas de satisfacción de restricciones (CSP) como Sudoku, N-Reinas y coloreo de mapas.

def n_reinas(n):
    """Resolver el problema de las N-Reinas con backtracking."""
    def es_seguro(tablero, fila, col):
        for i in range(fila):
            if tablero[i] == col or \
               abs(tablero[i] - col) == abs(i - fila):
                return False
        return True
    
    def resolver(tablero, fila):
        if fila == n:
            return True  # ¡Todas las reinas colocadas!
        for col in range(n):
            if es_seguro(tablero, fila, col):
                tablero[fila] = col
                if resolver(tablero, fila + 1):
                    return True
                tablero[fila] = -1  # Backtrack
        return False
    
    tablero = [-1] * n
    resolver(tablero, 0)
    return tablero

Ejercicio resuelto

Problema: Dado el grafo A→B, A→C, B→D, B→E, C→F, D→G (objetivo), muestra el orden de visita con BFS y DFS.

BFS (cola): A → B, C → D, E, F → G ✅. Orden: A, B, C, D, E, F, G.

DFS (pila): A → B → D → G ✅. Orden: A, B, D, G. (Encuentra más rápido porque G está en la rama izquierda profunda)

🎯 Conclusión

Los algoritmos de exploración son la base de la resolución de problemas en IA. BFS garantiza encontrar la solución óptima pero consume mucha memoria; DFS es eficiente en memoria pero puede no encontrar la mejor solución. Backtracking es fundamental para problemas de satisfacción de restricciones. En la industria, estos algoritmos se usan en navegación GPS, resolución de puzzles, análisis de grafos sociales y verificación de software.
