Lógica Difusa (Fuzzy Logic)

📖 Lectura: 12 min 🏷️ Unidad IV 📝 Tema 4.4

4.4.1 Conceptos Básicos

La lógica difusa (fuzzy logic), propuesta por Lotfi Zadeh en 1965, extiende la lógica clásica para manejar grados de verdad en lugar de verdadero/falso absoluto. Permite razonar con conceptos vagos como «alto», «caliente», «rápido» — tal como lo hace el pensamiento humano.

📐 Lógica clásica vs. difusa

Clásica: ¿La temperatura de 37°C es «caliente»? → SÍ o NO (0 o 1).
Difusa: ¿La temperatura de 37°C es «caliente»? → Es caliente con grado 0.7 y tibia con grado 0.3.

Los conjuntos difusos permiten que un elemento pertenezca parcialmente a un conjunto, con un valor de membresía μ ∈ [0, 1].

📊

Conjunto difuso

Conjunto donde la pertenencia no es binaria sino un grado entre 0 y 1. Ejemplo: μ_caliente(37°C) = 0.7.

📈

Función de membresía

Función que asigna el grado de pertenencia: triangular, trapezoidal, gaussiana, sigmoide.

🔗

Reglas difusas

SI temperatura ES caliente Y humedad ES alta ENTONCES ventilador ES rápido. Usan operadores difusos (AND, OR, NOT).

🎯

Defuzzificación

Convertir la salida difusa en un valor numérico concreto. Métodos: centroide, bisector, máximo.

El proceso de inferencia difusa

Paso 1

Fuzzificación

Convertir valores numéricos en grados de membresía. Ejemplo: temp=37°C → μ_fría=0.0, μ_tibia=0.3, μ_caliente=0.7.

Paso 2

Evaluación de reglas

Aplicar las reglas difusas usando operadores: AND=min, OR=max. Cada regla produce una salida difusa.

Paso 3

Agregación

Combinar las salidas de todas las reglas en un único conjunto difuso de salida.

Paso 4

Defuzzificación

Convertir el conjunto difuso agregado en un valor numérico concreto: ventilador = 72% de velocidad.

🎯 Actividad Práctica

💡 Ejercicio: Controlador difuso de propinas

Diseña un sistema difuso que calcule el porcentaje de propina en un restaurante basado en la calidad del servicio y la comida.

1. Variables de entrada: servicio (0-10), calidad_comida (0-10).

2. Variable de salida: propina (5%-25%).

A continuación tienes una implementación de referencia en Python utilizando scikit-fuzzy:

import numpy as np
import skfuzzy as fuzz
from skfuzzy import control as ctrl

# 1. Definir las variables de entrada y salida del universo
servicio = ctrl.Antecedent(np.arange(0, 11, 1), 'servicio')
comida = ctrl.Antecedent(np.arange(0, 11, 1), 'comida')
propina = ctrl.Consequent(np.arange(5, 26, 1), 'propina')

# 2. Poblado automático de funciones de membresía (poor, average, good)
servicio.automf(3)
comida.automf(3)

# 3. Definir funciones de membresía triangulares personalizadas para la salida
propina['baja'] = fuzz.trimf(propina.universe, [5, 5, 15])
propina['media'] = fuzz.trimf(propina.universe, [5, 15, 25])
propina['alta'] = fuzz.trimf(propina.universe, [15, 25, 25])

# 4. Establecer la base de conocimiento (Reglas Difusas)
regla1 = ctrl.Rule(servicio['poor'] | comida['poor'], propina['baja'])
regla2 = ctrl.Rule(servicio['average'], propina['media'])
regla3 = ctrl.Rule(servicio['good'] & comida['good'], propina['alta'])

# 5. Configurar el motor de inferencia y simulación
controlador_propinas = ctrl.ControlSystem([regla1, regla2, regla3])
asignacion = ctrl.ControlSystemSimulation(controlador_propinas)

# Enviar valores de prueba al sistema
asignacion.input['servicio'] = 7.5
asignacion.input['comida'] = 9.0

# Ejecutar el proceso de computación (Inferencia + Defuzzificación)
asignacion.compute()
print(f"Propina calculada: {asignacion.output['propina']:.2f}%")

3. Ejecuta el script en tu entorno local. Modifica las entradas para servicio=2.0 y comida=4.0. ¿Cómo responde el centroide de salida?

📝 Evaluación — Tema 4.4

Pregunta 1 de 5
¿Cuál es la diferencia fundamental entre la lógica clásica (booleana) y la lógica difusa?
A La lógica clásica solo maneja texto y la difusa se restringe a números enteros.
B La lógica clásica evalúa la verdad de manera binaria (0 o 1), mientras que la lógica difusa permite grados de pertenencia continuos dentro del intervalo [0, 1].
C La lógica difusa no hace uso de operadores como AND u OR.
D La lógica clásica es determinista y la difusa es puramente un cálculo probabilístico de eventos futuros.
✅ Correcto. La lógica difusa rompe el principio del tercero excluido de la lógica binaria tradicional, permitiendo modelar matices intermedios en conceptos ambiguos.
Pregunta 2 de 5
¿Qué función cumple una "Función de Membresía" (Membership Function) en un sistema difuso?
A Determina el límite de memoria dinámica que requiere el algoritmo en ejecución.
B Convierte cadenas de caracteres lingüísticos en código binario puro de máquina.
C Asigna a un valor cuantitativo continuo su correspondiente grado de pertenencia semántico a un conjunto difuso específico.
D Se encarga de mezclar las salidas de múltiples bases de datos relacionales automáticamente.
✅ Correcto. Las funciones de membresía definen la curva matemática (triangular, gaussiana, etc.) que mapea las entradas físicas en el dominio difuso.
Pregunta 3 de 5
¿Por qué es estrictamente necesario el paso de "Defuzzificación" al final del proceso de inferencia difusa?
A Porque los actuadores y hardware del mundo real exigen comandos numéricos precisos y concretos para operar, no un conjunto difuso.
B Para codificar los datos en formato JSON para servicios web en la nube.
C Con la finalidad de reducir la complejidad de tiempo de cómputo del script de Python.
D Para descartar las reglas de producción que dieron un valor igual a cero.
✅ Correcto. Los sistemas físicos necesitan una acción exacta (ej. ajustar el motor a 72.5 RPM), por lo que métodos como el Centroide transforman la salida abstracta en un número real nítido.
Pregunta 4 de 5
¿Cuál es el orden secuencial correcto de las etapas que componen el Pipeline de un motor de inferencia difusa?
A Defuzzificación → Inferencia → Fuzzificación → Agregación
B Fuzzificación → Evaluación de Reglas → Agregación → Defuzzificación
C Agregación → Inferencia → Selección → Normalización
D Fuzzificación → Codificación → Limpieza → Optimización
✅ Correcto. El flujo procesa los datos de entrada puros, mapea su membresía, dispara las reglas de control, combina los mapas resultantes y extrae el valor de salida numérico final.
Pregunta 5 de 5
¿Qué ventaja principal ofrece un sistema Neuro-Difuso Adaptativo (ANFIS) comparado con un diseño difuso convencional?
A No requiere el uso de librerías ni dependencias externas en su compilación.
B Reemplaza por completo las reglas lingüísticas lógicas por código puramente determinista.
C Combina la legibilidad e interpretabilidad de las reglas difusas con la capacidad de autoaprendizaje de las Redes Neuronales para ajustar los parámetros de membresía basándose en datos.
D Elimina cualquier necesidad de implementar la etapa de defuzzificación.
✅ Correcto. ANFIS aprovecha algoritmos similares a backpropagation para calibrar de forma automática las formas de las curvas difusas a partir de registros históricos de entrenamiento.

Conclusión

La lógica difusa es la herramienta ideal cuando el problema involucra imprecisión humana: conceptos vagos, opiniones subjetivas, mediciones ruidosas. Mientras la lógica clásica obliga a elegir «sí o no», la lógica difusa dice «depende, y aquí está el grado». Con scikit-fuzzy puedes implementar controladores difusos en pocos minutos.
