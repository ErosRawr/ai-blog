Arquitectura de un Sistema de Producción

📖 Lectura: 12 min 🏷️ Unidad III 📝 Tema 3.6

¿Cómo funciona un sistema de producción?

Un sistema de producción es una arquitectura computacional completa para construir sistemas inteligentes basados en reglas. Es como una fábrica donde los hechos son la materia prima, las reglas son las máquinas, y el motor de inferencia es el capataz que organiza la producción.

🏗️ Los tres pilares

Todo sistema de producción tiene exactamente tres componentes:
1. Memoria de trabajo (hechos) — lo que el sistema sabe ahora.
2. Base de conocimientos (reglas) — lo que el sistema puede hacer.
3. Mecanismo de control (motor de inferencia) — cómo decide qué hacer.

Componentes en detalle

📦

Memoria de trabajo

Base de datos dinámica de hechos actuales. Cambia durante la ejecución: hechos se agregan (assert), modifican (modify) o eliminan (retract). Es el «estado actual del mundo».

📚

Base de conocimientos

Conjunto estático de reglas de producción que codifican el conocimiento experto. No cambia durante la ejecución. Es el «manual del experto».

⚙️

Motor de inferencia

El algoritmo que ejecuta el ciclo Match → Resolve → Act. Decide qué reglas aplicar en qué orden. Es el «cerebro organizador».

🖥️

Interfaz de usuario

Componente opcional para recibir datos del usuario y mostrar resultados, explicaciones y recomendaciones del sistema.

Flujo de ejecución completo

Inicio

Carga de hechos iniciales

El usuario o un sistema externo introduce hechos en la memoria de trabajo: {temperatura=39, tos=sí, edad=25}.

Match

Pattern matching (algoritmo Rete)

El motor compara los patrones de todas las reglas con la memoria de trabajo usando el eficiente algoritmo Rete (Forgy, 1982). Resultado: conjunto de conflicto = {R1, R3, R7}.

Resolve

Resolución de conflictos

Selecciona la regla ganadora aplicando estrategias: prioridad, refractariedad (no repetir reglas con los mismos hechos), especificidad, recencia.

Act

Ejecución del consecuente

Se ejecutan las acciones del RHS: assert/modify/retract hechos, imprimir resultados, or halt.

Loop

Repetir hasta terminar

El ciclo vuelve a Match con la nueva memoria de trabajo. Termina cuando: no hay más reglas activables, se ejecuta HALT, o se alcanza la meta.

El algoritmo Rete

El algoritmo Rete (Forgy, 1982) es la innovación clave que hace prácticos los sistemas de producción. En vez de comparar cada regla con cada hecho en cada ciclo (O(R×F)), construye una red de compilación que memoriza coincidencias parciales.

💡 Analogía

Sin Rete: Un detective revisa todo el archivo de pistas cada vez que llega una nueva. Con Rete: Tiene un tablero organizado donde cada pista nueva se ubica automáticamente con las demás relacionadas. Solo procesa lo nuevo.

🎯 Actividad práctica

💡 Ejercicio: Diseña la arquitectura completa

Dominio: Sistema experto para selección de carrera universitaria.

1. Define la memoria de trabajo inicial: hechos sobre el estudiante (intereses, materias favoritas, habilidades, estilo de aprendizaje).

2. Escribe la base de conocimientos con al menos 10 reglas que mapeen perfiles a carreras recomendadas.

3. Dibuja el diagrama de arquitectura mostrando los tres componentes y sus relaciones.

4. Simula una ejecución completa: muestra 3 ciclos Match-Resolve-Act con un estudiante ejemplo.

Conclusión

La arquitectura de un sistema de producción es el blueprint de los sistemas expertos clásicos. La separación clara entre conocimiento (base de reglas), datos (memoria de trabajo) y control (motor de inferencia) permite construir sistemas mantenibles, escalables y explicables. CLIPS, Drools y OPS5 son implementaciones industriales que han demostrado el poder de esta arquitectura.
