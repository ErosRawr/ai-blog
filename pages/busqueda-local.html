1.8.3 Búsqueda Local

📖 Lectura: 30 min🏷️ Optimización📝 Tema 11 de 11

¿Qué es la búsqueda local?

La búsqueda local es una familia de algoritmos de optimización que operan a partir de una solución inicial y la mejoran iterativamente moviéndose a soluciones vecinas. A diferencia de búsquedas como BFS o A*, la búsqueda local no guarda el camino completo ni explora todo el árbol; solo mantiene el estado actual y sus vecinos.

Estas técnicas son ideales cuando:

  • El espacio de búsqueda es enorme (millones de estados).
  • Solo importa la solución, no el camino para llegar.
  • Se necesita una solución rápida y buena, aunque no perfecta.

Hill Climbing (Escalada)

Hill Climbing es el algoritmo de búsqueda local más simple. Funciona así:

  1. Comienza en un estado aleatorio.
  2. Evalúa todos los vecinos.
  3. Se mueve al vecino con mejor valor (si es mejor que el actual).
  4. Repite hasta que no haya vecino mejor → se detuvo en un pico.
⚠️ Problemas de Hill Climbing

Máximos locales: Se queda atrapado en un pico que no es el global.
Mesetas: Regiones planas donde todos los vecinos tienen el mismo valor.
Crestas: Superficies estrechas que son difíciles de recorrer.

import random

def hill_climbing(f, generar_vecinos, x_inicial, max_iter=1000):
    """
    Hill climbing para maximización.
    f: función objetivo a maximizar
    generar_vecinos: genera vecinos del estado actual
    """
    actual = x_inicial
    valor_actual = f(actual)
    
    for _ in range(max_iter):
        vecinos = generar_vecinos(actual)
        mejor_vecino = max(vecinos, key=f)
        valor_vecino = f(mejor_vecino)
        
        if valor_vecino <= valor_actual:
            break  # Máximo local alcanzado
        
        actual = mejor_vecino
        valor_actual = valor_vecino
    
    return actual, valor_actual

Simulated Annealing (Recocido Simulado)

Simulated Annealing (SA), propuesto por Kirkpatrick, Gelatt y Vecchi (1983), resuelve el problema de los máximos locales inspirándose en el proceso metalúrgico de recocido: calentar un metal y enfriarlo lentamente para obtener una estructura cristalina óptima.

La idea clave: permitir movimientos «malos» (subóptimos) con una probabilidad que decrece con el tiempo. Al inicio, el algoritmo explora libremente. Conforme la «temperatura» baja, se vuelve más selectivo.

🌡️ Probabilidad de aceptación

P(aceptar movimiento peor) = e^(−ΔE / T)

Donde ΔE = cambio en la función objetivo y T = temperatura actual. A temperatura alta, se aceptan muchos movimientos malos. A temperatura baja, casi ninguno.

import random
import math

def simulated_annealing(f, generar_vecino, x_inicial, 
                         T_inicial=1000, T_min=1, alpha=0.99):
    """Simulated Annealing para maximización."""
    actual = x_inicial
    valor_actual = f(actual)
    mejor = actual
    valor_mejor = valor_actual
    T = T_inicial
    
    while T > T_min:
        vecino = generar_vecino(actual)
        valor_vecino = f(vecino)
        delta = valor_vecino - valor_actual
        
        # Aceptar si es mejor, o con probabilidad e^(δ/T)
        if delta > 0 or random.random() < math.exp(delta / T):
            actual = vecino
            valor_actual = valor_vecino
        
        # Actualizar mejor solución global
        if valor_actual > valor_mejor:
            mejor = actual
            valor_mejor = valor_actual
        
        T *= alpha  # Enfriar
    
    return mejor, valor_mejor

Algoritmos Genéticos

Los Algoritmos Genéticos (AG), propuestos por John Holland (1975), se inspiran en la evolución biológica: mantienen una población de soluciones candidatas que evoluciona generación tras generación mediante selección, cruzamiento y mutación.

def algoritmo_genetico(fitness, n_poblacion=100, n_generaciones=500,
                        prob_crossover=0.8, prob_mutacion=0.05):
    # 1. Inicializar población aleatoria
    poblacion = [crear_individuo_aleatorio() for _ in range(n_poblacion)]
    
    for gen in range(n_generaciones):
        # 2. Evaluar fitness
        aptitudes = [fitness(ind) for ind in poblacion]
        
        # 3. Selección (torneo)
        padres = seleccion_torneo(poblacion, aptitudes)
        
        # 4. Crossover
        hijos = []
        for i in range(0, len(padres), 2):
            if random.random() < prob_crossover:
                h1, h2 = crossover(padres[i], padres[i+1])
            else:
                h1, h2 = padres[i], padres[i+1]
            hijos.extend([h1, h2])
        
        # 5. Mutación
        for i in range(len(hijos)):
            if random.random() < prob_mutacion:
                hijos[i] = mutar(hijos[i])
        
        # 6. Reemplazo
        poblacion = hijos
    
    # Retornar el mejor individuo
    return max(poblacion, key=fitness)

Actividad práctica

Ejercicio resuelto

Problema: Maximizar f(x) = −x² + 10x con Hill Climbing.

Derivada: f'(x) = −2x + 10 = 0 → x = 5 (máximo en x=5, f(5)=25).

Con Hill Climbing: Inicio x=0, vecinos x±1. x=0(0) → x=1(9) → x=2(16) → x=3(21) → x=4(24) → x=5(25) → x=6(24) ✗. Se detiene en x=5. ✅ Encontró el óptimo global (porque la función es unimodal).

🎯 Conclusión

La búsqueda local es esencial para problemas de optimización de gran escala donde las búsquedas exhaustivas son impracticables. Hill climbing es un punto de partida rápido pero miope. Simulated annealing añade exploración estocástica para escapar de óptimos locales. Los algoritmos genéticos aprovechan la diversidad poblacional para explorar el espacio de soluciones en paralelo. En la industria, estos algoritmos optimizan rutas de logística (TSP), diseño de circuitos (VLSI), scheduling de producción, y entrenamiento de redes neuronales.
