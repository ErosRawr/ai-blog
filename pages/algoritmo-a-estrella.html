1.8.2 Algoritmo A*

📖 Lectura: 30 min🏷️ Pathfinding📝 Tema 10 de 11

El rey de la búsqueda informada

El algoritmo A* (pronunciado «A estrella»), publicado por Hart, Nilsson y Raphael en 1968, es el algoritmo de búsqueda informada más importante y utilizado en la historia de la IA. Combina las ventajas de la búsqueda de costo uniforme (Dijkstra) con una heurística que guía la exploración hacia el objetivo.

La función de evaluación de cada nodo es:

📐 Fórmula fundamental de A*

f(n) = g(n) + h(n)

Donde:

  • g(n) = costo real del camino desde el inicio hasta n (conocido)
  • h(n) = estimación heurística del costo desde n hasta el objetivo (estimado)
  • f(n) = costo total estimado del camino a través de n

Propiedades de A*

Propiedad¿Cumple?Condición
Completo✅ SíSi hay solución y b es finito
Óptimo✅ SíSi h(n) es admisible (en búsqueda en árbol) o consistente (en búsqueda en grafo)
TiempoO(b^d) en peor casoPero típicamente mucho mejor con buena h
EspacioO(b^d)Guarda todos los nodos en memoria

Admisibilidad y Consistencia

  • Admisible: h(n) ≤ h*(n) para todo n. Nunca sobreestima. Garantiza que A* encuentra la solución óptima.
  • Consistente: h(n) ≤ c(n,n') + h(n') para todo sucesor n'. Implica admisibilidad. Garantiza que los nodos se expanden en orden óptimo.

Pseudocódigo

función A*(inicio, objetivo):
    ABIERTOS ← cola de prioridad con {inicio, g=0, f=h(inicio)}
    CERRADOS ← conjunto vacío
    
    mientras ABIERTOS no esté vacío:
        n ← extraer nodo con menor f de ABIERTOS
        
        si n == objetivo:
            retornar reconstruir_camino(n)
        
        agregar n a CERRADOS
        
        para cada sucesor s de n:
            si s está en CERRADOS:
                continuar
            
            g_nuevo ← g(n) + costo(n, s)
            
            si s no está en ABIERTOS o g_nuevo < g(s):
                padre(s) ← n
                g(s) ← g_nuevo
                f(s) ← g(s) + h(s)
                si s no está en ABIERTOS:
                    agregar s a ABIERTOS
    
    retornar "No hay solución"

Grafo: S→A(1), S→B(4), A→B(2), A→C(5), B→C(1), C→G(3). Heurísticas: h(S)=7, h(A)=6, h(B)=2, h(C)=1, h(G)=0.

Implementación en Python

import heapq

def a_star(grafo, inicio, objetivo, h):
    """
    Algoritmo A* con cola de prioridad.
    grafo: dict {nodo: [(vecino, costo), ...]}
    h: dict {nodo: valor_heurístico}
    """
    abiertos = [(h[inicio], 0, inicio, [inicio])]  # (f, g, nodo, camino)
    cerrados = set()
    g_mejor = {inicio: 0}
    
    while abiertos:
        f, g, nodo, camino = heapq.heappop(abiertos)
        
        if nodo == objetivo:
            return camino, g  # Camino óptimo y costo
        
        if nodo in cerrados:
            continue
        cerrados.add(nodo)
        
        for vecino, costo in grafo.get(nodo, []):
            g_nuevo = g + costo
            if vecino not in cerrados and \
               (vecino not in g_mejor or g_nuevo < g_mejor[vecino]):
                g_mejor[vecino] = g_nuevo
                f_nuevo = g_nuevo + h.get(vecino, 0)
                heapq.heappush(abiertos, (f_nuevo, g_nuevo, vecino, camino + [vecino]))
    
    return None, float('inf')

# Ejemplo de uso
grafo = {
    'S': [('A', 1), ('B', 4)],
    'A': [('B', 2), ('C', 5)],
    'B': [('C', 1)],
    'C': [('G', 3)]
}
h = {'S': 7, 'A': 6, 'B': 2, 'C': 1, 'G': 0}

camino, costo = a_star(grafo, 'S', 'G', h)
print(f"Camino: {' → '.join(camino)}")  # S → B → C → G
print(f"Costo: {costo}")  # 8

Aplicaciones de A*

🗺️

GPS y navegación

Google Maps, Waze y sistemas de navegación usan variantes de A* para encontrar la ruta más corta en grafos de millones de nodos.

🎮

Videojuegos

Pathfinding de NPCs. Todos los motores de juegos (Unity, Unreal) implementan A* para movimiento inteligente.

🤖

Robótica

Planificación de movimientos de robots en entornos con obstáculos. ROS usa A* y sus variantes.

🧬

Bioinformática

Alineamiento de secuencias de ADN, plegamiento de proteínas, diseño de fármacos.

🎯 Conclusión

A* es el algoritmo de búsqueda informada más utilizado en la industria. Su elegante combinación de costo real y estimación heurística lo hace óptimo y eficiente cuando se usa con heurísticas admisibles. Desde videojuegos hasta GPS, robótica y bioinformática, A* sigue siendo una pieza fundamental del toolkit del ingeniero ISC.
