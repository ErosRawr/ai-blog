Sistemas Expertos

📖 Lectura: 14 min 🏷️ Unidad IV 📝 Tema 4.6

4.6.1 Conceptos Básicos

Un sistema experto (SE) es un programa de IA que emula el conocimiento y razonamiento de un experto humano en un dominio específico. Fue la primera aplicación comercial exitosa de la IA, popularizada en los años 80.

🏗️ Arquitectura de un sistema experto

Base de conocimientos: Reglas de producción y hechos del dominio (el «saber» del experto).
Motor de inferencia: Algoritmo que aplica las reglas (forward/backward chaining).
Memoria de trabajo: Hechos del caso actual que se está resolviendo.
Módulo de explicación: Justifica sus conclusiones al usuario («¿por qué llegaste a esa conclusión?»).
Interfaz de usuario: Permite al usuario ingresar datos y ver resultados.
Módulo de adquisición: Herramientas para que el ingeniero del conocimiento añada reglas.

👨‍⚕️

Experto humano

Persona con años de experiencia en el dominio. Su conocimiento se extrae y codifica en reglas.

🔧

Ingeniero del conocimiento

Especialista que entrevista al experto y traduce su saber en reglas formales para el sistema.

👤

Usuario final

Persona no experta que consulta al sistema para obtener diagnósticos, recomendaciones o soluciones.

4.6.3 Desarrollos Actuales y Aplicaciones

Clásico

MYCIN (1976) — el pionero

Sistema de diagnóstico de infecciones bacterianas de Stanford. 600 reglas, precisión comparable a especialistas. Introdujo factores de certeza.

Industria

Motores de reglas de negocio

Drools (Java), CLIPS (C), Jess (Java): sistemas de producción usados en banca, seguros, telecomunicaciones para automatizar decisiones.

Moderno

SE + Machine Learning

Sistemas híbridos: reglas para lógica de negocio + ML para predicción. Explicable AI (XAI) retoma la filosofía de los SE.

Actual

LLMs como «expertos» generales

ChatGPT y similares actúan como SE generalistas, pero carecen de garantías formales. Los SE clásicos siguen siendo preferidos en dominios críticos (medicina, aviación).

🛠️ Herramientas clave

CLIPS: Entorno clásico para construir SE basados en reglas (open source).
Drools: Motor de reglas empresarial en Java (Red Hat).
Pyknow / Experta: Framework Python para SE (inspirado en CLIPS).
Protégé: Editor de ontologías para bases de conocimiento complejas.

⚠️ SE vs. LLMs: ¿cuándo usar cada uno?

Usa SE cuando: necesitas explicabilidad total, el dominio es bien definido, hay regulación estricta (medicina, finanzas), las reglas no cambian frecuentemente.
Usa LLMs cuando: el dominio es abierto, se necesita flexibilidad con lenguaje natural, los datos son masivos y cambiantes, la precisión «perfeccionable» es aceptable.

🎯 Actividad Práctica

💡 Ejercicio: Construye un mini sistema experto

Dominio: Diagnóstico de problemas de red en una empresa.

1. Entrevista a un «experto» (puedes ser tú mismo): lista los 10 problemas de red más comunes y sus síntomas.

2. Codifica al menos 15 reglas en pseudocódigo o con la librería Experta de Python.

3. Implementa el módulo de explicación: cuando dé un diagnóstico, debe mostrar las reglas que usó.

4. Prueba con 5 casos de prueba. ¿El SE diagnostica correctamente?

5. ¿Qué límites tiene tu sistema? ¿Qué haría falta para desplegarlo en producción?

Conclusión

Los sistemas expertos son la aplicación clásica más exitosa de la IA simbólica. Aunque la era de los LLMs ha cambiado el panorama, los SE siguen siendo insustituibles en dominios donde la explicabilidad, trazabilidad y garantía formal son obligatorias. CLIPS, Drools y Experta permiten construir SE funcionales hoy. El futuro está en la combinación: reglas formales para lógica de negocio + ML para predicción + LLMs para interfaz natural.
