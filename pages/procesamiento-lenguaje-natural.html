Procesamiento de Lenguaje Natural

📖 Lectura: 14 min 🏷️ Unidad IV 📝 Tema 4.5

4.5.1 Conceptos Básicos

El Procesamiento de Lenguaje Natural (PLN/NLP) es el campo de la IA que permite a las máquinas entender, interpretar y generar lenguaje humano. Es la tecnología detrás de ChatGPT, traductores automáticos, asistentes de voz y buscadores modernos.

✂️

Tokenización

Dividir texto en unidades: palabras, subpalabras o caracteres. BPE (Byte-Pair Encoding) es el estándar actual.

🏷️

POS Tagging

Etiquetar cada palabra con su categoría gramatical: sustantivo, verbo, adjetivo, etc.

🔢

Embeddings

Representar palabras como vectores densos: Word2Vec, GloVe, FastText. «Rey - Hombre + Mujer ≈ Reina».

🧠

Modelos de lenguaje

Predecir la siguiente palabra. Fundamento de GPT, BERT y todos los LLMs modernos.

📐 Pipeline clásico de NLP

1. Preprocesamiento: Tokenización, lowercasing, eliminación de stopwords, stemming/lemmatización.
2. Representación: Bag of Words, TF-IDF, o embeddings (Word2Vec, Transformers).
3. Modelado: Clasificadores (Naive Bayes, SVM, RNNs, Transformers).
4. Evaluación: Accuracy, F1-score, BLEU (traducción), ROUGE (resumen).

4.5.2 Desarrollos Actuales y Aplicaciones

2018

BERT (Google)

Pre-entrenamiento bidireccional. Revolucionó la comprensión de texto. Base para búsqueda, Q&A, clasificación.

2020-2023

GPT-3 / GPT-4 (OpenAI)

Modelos generativos masivos. ChatGPT democratizó el acceso a LLMs. Generación de texto, código, razonamiento.

2024-2026

LLMs multimodales

Gemini, Claude, GPT-4o: entienden texto + imagen + audio + video. Razonamiento multimodal y agentes autónomos.

🛠️ Herramientas clave

NLTK: Librería clásica de NLP en Python (tokenización, stemming, corpus).
spaCy: NLP industrial — rápido, con modelos pre-entrenados en español.
Hugging Face Transformers: Acceso a BERT, GPT, T5 y miles de modelos.
LangChain: Framework para construir apps con LLMs (RAG, agentes).

🎯 Actividad Práctica

💡 Ejercicio: Análisis de Sentimiento Comparativo

Vamos a comparar el enfoque clásico (NLTK) con un enfoque moderno basado en Transformers (Hugging Face) para analizar la misma oración.

import nltk
from nltk.sentiment import SentimentIntensityAnalyzer
from transformers import pipeline

# 1. Configurar y usar NLTK (Léxico clásico VADER)
nltk.download('vader_lexicon', quiet=True)
sia = SentimentIntensityAnalyzer()

reseña = "El producto es increíble, me encantó la calidad pero el envío fue algo lento."

print("--- Análisis de Sentimiento con NLTK ---")
puntajes_nltk = sia.polarity_scores(reseña)
print(f"Resultados VADER: {puntajes_nltk}")
# Salida esperada: Un diccionario con scores negativos, neutrales, positivos y el "compound" (total).

# 2. Configurar y usar Hugging Face (Modelo Deep Learning preentrenado)
print("\n--- Análisis de Sentimiento con Transformers ---")
# Descarga automáticamente un modelo multilingüe para sentimiento
clasificador = pipeline("sentiment-analysis", model="nlptown/bert-base-multilingual-uncased-sentiment")

resultado_hf = clasificador(reseña)
print(f"Resultados HuggingFace: {resultado_hf}")
# Salida esperada: Una etiqueta (ej. "4 stars") y su nivel de confianza (score).

Análisis: Ejecuta el código. ¿Cómo maneja VADER la conjunción "pero" en comparación con la comprensión contextual completa del modelo de Hugging Face?

📝 Evaluación — Tema 4.5

Pregunta 1 de 5
¿Por qué el algoritmo de tokenización BPE (Byte-Pair Encoding) es el estándar en los Grandes Modelos de Lenguaje (LLMs)?
A Porque procesa únicamente caracteres individuales, reduciendo el tamaño del modelo a un megabyte.
B Porque divide inteligentemente las palabras raras o desconocidas en subpalabras frecuentes, logrando un balance perfecto entre eficiencia y vocabulario.
C Porque elimina todas las vocales de un texto automáticamente para acelerar el entrenamiento.
D Porque solo funciona con el idioma inglés, evitando confusiones de traducción.
✅ Correcto. BPE fusiona los pares de bytes más comunes, creando "tokens" que pueden ser palabras enteras (si son muy comunes) o fragmentos (para palabras complejas).
Pregunta 2 de 5
¿Qué ventaja clave ofrecen los "Word Embeddings" (como Word2Vec) sobre los métodos tradicionales como "Bag of Words" (BoW)?
A Capturan relaciones semánticas y de contexto espacial, permitiendo entender que "rey" está relacionado con "reina".
B Consumen exactamente el mismo espacio de memoria pero corren más rápido en Python.
C Se limitan a contar la frecuencia de aparición de una palabra en un texto, ignorando la gramática.
D Eliminan la necesidad de realizar tokenización previa.
✅ Correcto. Los Embeddings representan las palabras como vectores densos en un espacio multidimensional donde palabras con significados similares están matemáticamente cerca.
Pregunta 3 de 5
En la arquitectura Transformer, ¿cuál es la diferencia principal entre los modelos BERT y GPT?
A BERT genera imágenes a partir de texto, mientras que GPT es exclusivo para audio.
B GPT fue creado por Google en 2018, y BERT por OpenAI en 2020.
C BERT es bidireccional (usa el codificador/encoder) ideal para comprender contexto global; GPT es unidireccional (usa el decodificador/decoder) ideal para generar texto.
D Son exactamente la misma arquitectura pero programados en lenguajes distintos.
✅ Correcto. BERT "lee" toda la frase al mismo tiempo para extraer significado (ideal para búsqueda), mientras GPT predice la siguiente palabra leyendo de izquierda a derecha (ideal para chat).
Pregunta 4 de 5
Si necesitas extraer automáticamente nombres de personas, ubicaciones geográficas y fechas de un artículo de noticias, ¿qué tarea de NLP estás realizando?
A POS Tagging (Etiquetado gramatical)
B Análisis de Sentimiento
C NER (Named Entity Recognition - Reconocimiento de Entidades Nombradas)
D Traducción Automática
✅ Correcto. El NER es vital para estructurar información libre, y librerías modernas como spaCy lo ejecutan con alta precisión.
Pregunta 5 de 5
¿Qué librería está consolidada como el framework principal para orquestar y construir aplicaciones avanzadas (como RAG o agentes) conectando LLMs con bases de datos?
A VADER
B Word2Vec
C NLTK
D LangChain
✅ Correcto. LangChain permite que un LLM tenga "memoria", lea documentos externos y ejecute herramientas encadenadas para crear asistentes virtuales completos.

Conclusión

El NLP es posiblemente el campo de la IA con mayor impacto visible en la sociedad actual. Los LLMs han transformado cómo interactuamos con la tecnología: buscamos, escribimos, traducimos y programamos con la ayuda de modelos que «entienden» nuestro idioma. Con NLTK, spaCy y Hugging Face, cualquier desarrollador puede implementar NLP de nivel profesional.
