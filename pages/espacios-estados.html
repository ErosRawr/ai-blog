Espacios de Estados Determinísticos y No Determinísticos

📖 Lectura: 12 min 🏷️ Unidad III 📝 Tema 3.6

¿Qué es un espacio de estados?

Un espacio de estados es una representación formal de un problema como un grafo donde cada nodo es un estado (configuración del problema) y cada arista es una transición (acción que transforma un estado en otro).

Imagina el juego del 8-puzzle: cada configuración posible de las fichas es un estado, y cada movimiento válido (mover ficha arriba, abajo, izquierda, derecha) es una transición. Resolver el puzzle es encontrar un camino desde el estado inicial hasta el estado meta.

📐 Definición formal

Un espacio de estados se define como la tupla (S, s₀, G, A, T):
S = conjunto de todos los estados posibles.
s₀ = estado inicial.
G = conjunto de estados meta.
A = conjunto de acciones disponibles.
T = función de transición: T(s, a) → s'.

Determinístico vs. No Determinístico

🎯

Determinístico

Cada acción en un estado produce exactamente un estado sucesor. T(s,a) = {s'}. Se sabe con certeza qué pasará. Ejemplo: ajedrez, 8-puzzle, Rubik's cube.

🎲

No Determinístico

Una acción puede producir varios estados posibles. T(s,a) = {s₁', s₂', ...}. Hay incertidumbre. Ejemplo: backgammon (dados), navegación con viento, IA en videojuegos.

AspectoDeterminísticoNo Determinístico
Resultado de acciónÚnico y predecibleMúltiple, con probabilidades
PlanificaciónUn solo plan lineal bastaSe necesitan planes condicionales o políticas
ComplejidadMenor (espacio de búsqueda fijo)Mayor (espacio de búsqueda ramificado)
AlgoritmosBFS, DFS, A*AND-OR search, MDP, MCTS
Ejemplo8-puzzle, laberintoBackgammon, robot con sensores ruidosos

Ejemplo: aspiradora robot

// Modelado formal del Espacio de Estados — Aspiradora en 2 habitaciones (A y B)
const estado = {
    robot: "A",       // Ubicación del agente: "A" o "B"
    habitacionA: "SÚC_IA", // Estado de la superficie A: "SÚC_IA" o "LIMPIA"
    habitacionB: "SÚC_IA"  // Estado de la superficie B: "SÚC_IA" o "LIMPIA"
};

// Acciones válidas libres de contexto
const acciones = ["IZQUIERDA", "DERECHA", "ASPIRAR"];

// Modelo Transicional DETERMINÍSTICO
function transicionDeterminista(estadoActual, accion) {
    if (accion === "ASPIRAR" && estadoActual.robot === "A") {
        return { ...estadoActual, habitacionA: "LIMPIA" }; 
        // Resultado único, exacto y garantizado
    }
    return estadoActual;
}

// Modelo Transicional NO DETERMINÍSTICO
function transicionNoDeterminista(estadoActual, accion) {
    if (accion === "ASPIRAR" && estadoActual.robot === "A") {
        const probabilidadExito = Math.random() < 0.90; 
        return {
            ...estadoActual,
            habitacionA: probabilidadExito ? "LIMPIA" : "SÚC_IA" 
            // El actuador falla un 10% de las veces reteniendo suciedad
        };
    }
    return estadoActual;
}

🎯 Actividad práctica

💡 Ejercicio: Modela un espacio de estados

Problema: El puzzle de los misioneros y caníbales.

3 misioneros y 3 caníbales deben cruzar un río en un bote para 2 personas. Nunca deben quedar más caníbales que misioneros en ningún lado.

a) Define formalmente (S, s₀, G, A, T).

b) ¿Es determinístico o no determinístico? Justifica.

c) Dibuja al menos 8 estados y sus transiciones.

d) ¿Cuántos estados totales tiene este problema? ¿Cuántos son válidos?

e) Encuentra un camino solución del estado inicial al estado meta.

Pregunta 1 de 5
¿Qué componentes integran la tupla formal (S, s₀, G, A, T) que define un espacio de estados?
A Sensores, Servidores, Gráficos, Algoritmos y Tensores.
B Conjunto de estados, Estado inicial, Estados meta, Acciones y Función de transición.
C Sintaxis, Semántica, Grafos de control, Árboles y Terminales.
D Hechos, Reglas de inferencia, Base del conocimiento, Agendas y Motores.
✅ Correcto. Estos cinco elementos matemáticos describen y acotan por completo un problema de búsqueda formal.
Pregunta 2 de 5
¿Cuál es la principal característica de un espacio de estados No Determinístico?
A El costo de los caminos solución varía de forma aleatoria a cada segundo.
B Carece de estados meta u objetivos explícitos en su tupla de diseño.
C Una única acción ejecutada bajo un mismo estado puede mapear a múltiples estados sucesores posibles.
D Obliga al algoritmo a procesar ramificaciones exclusivamente de forma lineal y secuencial.
✅ Correcto. Al no tener certeza absoluta del estado resultante, se introduce incertidumbre en el proceso de transiciones.
Pregunta 3 de 5
¿Por qué la planificación en entornos no determinísticos requiere planes condicionales o políticas en lugar de planes lineales simples?
A Porque el agente inteligente debe estar preparado con ramificaciones lógicas para responder ante imprevistos o fallas del entorno.
B Porque los entornos lineales provocan fugas de memoria y desbordamientos en motores reactivos.
C Debido a que algoritmos clásicos como A* no admiten matrices multidimensionales.
D Para reducir de forma artificial el tamaño de las tablas de datos operativas.
✅ Correcto. Las estructuras condicionales (si pasa s₁ ejecutar a₁, si pasa s₂ ejecutar a₂) garantizan alcanzar la meta a pesar de la incertidumbre.
Pregunta 4 de 5
En el ejemplo probabilístico de la aspiradora inteligente, ¿qué representa el 10% asignado a la condición de falla?
A La porción de memoria de trabajo consumida por el recolector de basura de JS.
B La incertidumbre o imperfección física del actuador al no limpiar efectivamente la superficie.
C La cantidad de polvo remanente que se esparce de forma cíclica por la habitación.
D El porcentaje de batería consumido por cada acción de aspirado realizada.
✅ Correcto. Modela las imperfecciones del mundo real, donde las acciones del hardware no siempre tienen resultados perfectos.
Pregunta 5 de 5
¿A qué refiere el concepto de «explosión combinatoria» al explorar un espacio de estados?
A A la corrupción de punteros internos al procesar grafos cíclicos concurrentes.
B Al crecimiento exponencial del número de estados a medida que aumenta la profundidad o variables del problema.
C Al borrado masivo de nodos estériles o inalcanzables en un árbol de decisión AND-OR.
D Al fallo de un algoritmo de búsqueda ciega cuando encuentra múltiples estados meta contiguos.
✅ Correcto. Este fenómeno limita la viabilidad de resolver problemas complejos por fuerza bruta, haciendo necesaria la introducción de funciones heurísticas.

Conclusión

Los espacios de estados son la representación formal más usada para modelar problemas de búsqueda y planificación en IA. Comprender la diferencia entre espacios determinísticos y no determinísticos es clave para elegir los algoritmos correctos.
